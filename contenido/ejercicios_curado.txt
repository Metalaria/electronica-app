# Lo lee contenido/ejercicios.py y sustituye, para cada etiqueta que aparece aquí, lo que el analizador
# automático haya sacado de la solución. Formato:
#
#   [ej-5.1]                       etiqueta del ejercicio o del problema (refs.json)
#   = Nombre | valor unidad [±tol] [(nota)] | alternativa [(nota)] | …
#                                  un campo de respuesta numérica. Nombre admite V_R, V_{CE}, x^2, **negrita**.
#                                  tol: «±3%» relativa; «±0,05 V» absoluta (en la unidad escrita); «±0,5 pp»
#                                  puntos porcentuales; «±0,001» absoluta sin unidad. Sin tol: la del redondeo
#                                  del libro, entre el 2 % y el 6 %. Las alternativas (valor comercial, otro
#                                  redondeo, otra opción válida) se aceptan igual; la nota se muestra al acertar.
#   ~ clase: texto                 parte de la pregunta que no se comprueba sola (se muestra antes de resolver:
#                                  describe lo que se pide, no la respuesta). Clases: eleccion, texto,
#                                  deduccion, diseno, razonamiento. Sin ningún «=», el ejercicio queda en modo
#                                  «comparar con la solución» con la clase del primer «~».
#   sin-respuestas                 fuerza el modo «comparar» aunque el analizador encontrara números.
#   1: pista 1                     el planteamiento (la fórmula o el método), sin números del resultado.
#   2: pista 2                     un resultado intermedio.
#   errata: texto                  un error de la solución del libro (se muestra como aviso).
#   nota: texto                    aclaración para el lector.
#
# Las líneas que empiezan por # son comentarios.
